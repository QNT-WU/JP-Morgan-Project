# Basic Model (k, z) — Mailer/MMW Objectives in TensorFlow

This repository implements the basic stochastic growth model with state variables
(k_t, z_t) using TensorFlow and TensorFlow Probability, following the
Mailer framework.

The code implements three objectives:
1. Lifetime reward maximization
2. Euler residual minimization
3. Bellman + Euler residual minimization

It produces effectiveness-measure plots and ergodic-set plots.

## Installation

```bash
pip install -e .
```
